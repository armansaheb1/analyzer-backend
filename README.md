# Analyzer

AI-powered productivity and content generation platform built with Django, DRF, OpenAI and Google Gemini.

## Overview

Analyzer is a multi-service AI platform designed to help users generate content, analyze information, process news, and automate AI-assisted workflows.

The platform integrates multiple AI providers and includes authentication, content generation, news processing, and administrative management tools.

## Features

- AI content generation
- News collection and processing
- OpenAI integration
- Google Gemini integration
- User authentication and authorization
- REST API architecture
- Admin dashboard
- Category-based content management
- Automated workflows
